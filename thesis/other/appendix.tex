\section{Appendix Guideline}

The appendix contains supplementary material not essential for the main text but provides additional context or detail. Include items like detailed derivations, raw data, extended protocols, questionnaires, or supplementary code. Each appendix should have a clear title (using \texttt{\textbackslash section*} or \texttt{\textbackslash chapter*}) and be referenced appropriately in the main text. Keep the content relevant and organized.
