\chapter{Case Study: Controlled Pendulum System}
\label{chap:case_study}

Chapter~\ref{chap:implementation} verified the main \syssimx{} features in isolation.
This chapter evaluates their combined use in a controlled-pendulum case study.
The case study connects a reference trajectory, sensor feedback, a controller, an actuator, and a pendulum plant in one closed-loop system.

The chapter first defines the validation strategy.
It then introduces the controlled-pendulum system, the pendulum model variants, and the monolithic reference models.
The final part evaluates selected scenarios and discusses the observed accuracy, event behavior, model-switching behavior, and computational cost.
