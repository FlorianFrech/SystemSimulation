\section{Modeling Approaches}
\label{sec:24_modeling_approaches}

This thesis uses subsystem models from three modeling approaches at different abstraction levels.
Equation-based models describe lumped-parameter multi-domain behavior.
Musculoskeletal models describe articulated rigid-body dynamics with biomechanical semantics.
Finite element models describe spatially distributed deformation and contact effects.
This section characterizes these approaches at the level needed to understand the framework architecture, the implementation chapters, and the controlled-pendulum case study.
The selection of the concrete tools is discussed in Chapter~\ref{chap:requirements}.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Equation-Based Modeling}
\label{sec:241_modeling_equation_based}

Section~\ref{sec:intro_sota} introduced equation-based modeling as a compact way to describe lumped-parameter multi-domain subsystems.
Section~\ref{sec:21_continuous_time} formalized the corresponding state-space and differential-equation representation.
This subsection connects both views.
It shows how an equation-based source model expresses physical relations and how a modeling tool translates this source model into an executable simulation unit for co-simulation.
The pendulum from Section~\ref{sec:211_dynamical_systems} serves as the running example, and Modelica~\cite{Modelica_Fritzson} is used as a representative equation-based language.

Listing~\ref{lst:modelica_pendulum} shows a minimal Modelica realization of the pendulum.
The model declares the physical parameters $m$, $L$, and $I$, the gravitational acceleration $g$, and the initial conditions $\theta_0$ and $\omega_0$.
Its external interface consists of the input torque $\tau$ and the outputs $\theta$ and $\omega$.
The \texttt{equation} section states the two ordinary differential equations from Equation~\eqref{eq:pendulum_ode}.
It defines mathematical relations rather than an execution order.

\begin{listing}[htbp]
\begin{lstlisting}[style=modelica]
model Pendulum
  parameter Real m(unit="kg")          "Pendulum mass";
  parameter Real L(unit="m")           "Hinge to center of mass";
  parameter Real I(unit="kg.m2")       "Moment of inertia about pivot";
  parameter Real theta_0(unit="rad")   "Initial angle";
  parameter Real omega_0(unit="rad/s") "Initial angular velocity";
  constant  Real g(unit="m/s2")        "Gravitational accel.";

  Modelica.Blocks.Interfaces.RealInput  tau(unit="N.m");
  Modelica.Blocks.Interfaces.RealOutput theta(unit="rad");
  Modelica.Blocks.Interfaces.RealOutput omega(unit="rad/s");

initial equation
  theta = theta_0;
  omega = omega_0;

equation
  der(theta) = omega;
  der(omega) = (tau - m * g * L * sin(theta)) / I;
end Pendulum;
\end{lstlisting}
\caption[Modelica pendulum realization]{Modelica realization of the pendulum from Section~\ref{sec:211_dynamical_systems}. Parameter values are omitted.}
\label{lst:modelica_pendulum}
\end{listing}

The declarations in Listing~\ref{lst:modelica_pendulum} correspond to the quantities of the state-space form introduced in Section~\ref{sec:211_dynamical_systems}.
Constants such as $g$ are fixed physical quantities.
Parameters such as $m$, $L$, and $I$ are configuration values that are assigned before initialization and remain fixed during a simulation run.
Variables are time-dependent quantities and include states, inputs, and outputs.
For the pendulum, the state is $(\theta,\omega)$, the input is $\tau$, and the outputs are $\theta$ and $\omega$.

The \texttt{equation} section states relations between variables rather than assignments.
Although \texttt{der(theta) = omega} resembles an assignment, Modelica treats it as an equality that may be solved in either direction.
The computational direction is therefore determined during translation, not by the textual order of the source model.
Only the declared \texttt{RealInput} and \texttt{RealOutput} connectors define the external signal interface.

The translation from a source model to an executable simulation unit proceeds in three conceptual stages~\cite{Modelica_Fritzson}.
First, the modeling tool flattens the model.
Class hierarchies are resolved and connection equations are expanded, yielding a flat system of differential and algebraic equations.
Second, the tool performs structural analysis on this equation system.
It determines computational dependencies, sorts equations and variables, and applies index reduction if the system contains high-index \acp{DAE}.
Third, the sorted system is translated into executable code and linked with a numerical solver.
For co-simulation, this executable unit can be packaged as an \ac{FMU}.

When the translated model is used as a simulation unit, its accessible quantities follow from the variability and causality declarations of the source model.
Constants and parameters define the configuration before advancement, inputs are written by the master algorithm at communication points, and outputs are read as interface variables.
For co-simulation, the packaged unit may also expose structural information such as direct-feedthrough dependencies.
The concrete mapping of these declarations to framework ports and runtime calls is described in Chapter~\ref{chap:implementation}.

\subsection{Musculoskeletal Modeling}
\label{sec:242_modeling_musculoskeletal}

Section~\ref{sec:intro_sota} introduced musculoskeletal modeling as a domain-specific approach for systems that interact mechanically with the human body.
This subsection describes the multibody structure behind such models and the additional biomechanical semantics that distinguish them from generic lumped-parameter models.
OpenSim~\cite{OpenSim_Delp,seth_opensim_2018} is used as the representative tool.
Its dynamics computations are performed by the Simbody multibody engine~\cite{sherman_simbody_2011}.
The pendulum from Section~\ref{sec:211_dynamical_systems} serves as a minimal running example.

\paragraph{Multibody Topology.}
A musculoskeletal model is built from rigid bodies, joints, coordinates, and force elements.
The bodies define the inertial properties of the modeled segments.
The joints define the admissible relative motion between bodies and introduce generalized coordinates.
For the pendulum example in Figure~\ref{fig:opensim_pendulum_topology}, a pin joint introduces one generalized coordinate, the pendulum angle~$\theta$.
This coordinate corresponds to the angular state variable used in Section~\ref{sec:211_dynamical_systems}.

\begin{figure}[htbp]
    \centering
    \includegraphics[width=\textwidth]{figures/2_theoretical_background/multibody_topology.pdf}
    \caption[Multibody pendulum topology]{Multibody topology of the pendulum used as running example.
    A fixed base is connected to the pendulum body by a pin joint.
    The pin joint introduces the generalized coordinate~$\theta$.}
    \label{fig:opensim_pendulum_topology}
\end{figure}

\paragraph{Equations of Motion.}
A multibody model can be formulated in generalized coordinates
\(\boldsymbol{\eta} \in \mathbb{R}^{n_\eta}\).
Its equations of motion have the form
\begin{equation}
    \mathbf{M}(\boldsymbol{\eta})\,\ddot{\boldsymbol{\eta}}
    =
    \boldsymbol{\tau}
    -
    \mathbf{C}(\boldsymbol{\eta},\dot{\boldsymbol{\eta}})
    -
    \mathbf{G}(\boldsymbol{\eta})
    +
    \mathbf{Q}_{\mathrm{ext}},
    \label{eq:multibody_eom}
\end{equation}
where \(\mathbf{M}\) is the configuration-dependent mass matrix, \(\mathbf{C}\) collects velocity-dependent forces, \(\mathbf{G}\) collects gravitational forces, \(\boldsymbol{\tau}\) denotes generalized actuator forces, and \(\mathbf{Q}_{\mathrm{ext}}\) denotes additional external generalized forces~\cite{OpenSim_Delp,seth_opensim_2018}.
For the single-coordinate pendulum, \(\boldsymbol{\eta}=\theta\), the mass matrix reduces to the scalar moment of inertia~\(I\), and the gravitational contribution reduces to \(mgL\sin\theta\).
The resulting scalar equation matches the pendulum \ac{ODE} from Equation~\eqref{eq:pendulum_ode}.

\paragraph{Forces, Actuation, and Forward Dynamics.}
OpenSim models may contain passive forces, ideal actuators, contact forces, and muscle-tendon actuators.
Passive force elements describe effects such as springs, damping, and contact.
Ideal actuators apply prescribed generalized forces or torques to coordinates.
Muscle-tendon actuators add biomechanical state variables such as activation and fibre length and map muscle forces to joint torques through moment arms.

These advanced biomechanical elements are relevant for applications such as prostheses and exoskeletons, where the technical device interacts with a human musculoskeletal system.
The controlled-pendulum case study uses only the simpler multibody part of this capability.
It represents the plant as a rigid pendulum with an ideal torque input so that the OpenSim variant remains comparable to the equation-based pendulum.

Forward dynamics computes the state trajectory from initial coordinates, initial speeds, and a time history of applied controls.
The generalized accelerations follow from Equation~\eqref{eq:multibody_eom}, and numerical integration advances the generalized coordinates and speeds.
This differs from inverse dynamics, where a prescribed motion is given and the required generalized forces are computed~\cite{OpenSim_Delp,seth_opensim_2018}.

\paragraph{Staged Computation.}
OpenSim computes derived quantities through staged realization, in which each stage depends on the preceding ones.
Accelerations, for example, can be evaluated only after positions, velocities, and forces are available.
The selected realized quantities then become the outputs of the simulation unit.

\paragraph{Interface Consequence.}
A musculoskeletal model does not define a standardized co-simulation descriptor comparable to an \ac{FMI} model description.
The exchanged quantities must therefore be selected for the concrete model.
Typical inputs are actuator controls, prescribed generalized forces, or external loads.
Typical outputs are generalized coordinates, speeds, accelerations, body kinematics, contact quantities, or muscle-related quantities.
This model-specific interface selection is the main consequence for co-simulation.
The concrete wrapper mapping is described in Section~\ref{sec:impl_opensim}.

\subsection{Finite Element Modeling}
\label{sec:243_modeling_fem}

Section~\ref{sec:intro_sota} introduced finite element analysis as a way to resolve spatially distributed effects that lumped-parameter models cannot capture.
The equation-based and musculoskeletal approaches of the preceding subsections predict global kinematics and kinetics efficiently but do not resolve quantities within the subsystem geometry.
When local deformation, stress, or distributed contact must be evaluated explicitly, a spatially resolved formulation is required.
Finite element analysis provides this capability by discretizing the geometry into elements and approximating the solution field over that mesh~\cite{knothe_finite_2017}.

This subsection gives the continuum-mechanical and numerical concepts needed for the finite element pendulum used later in this thesis.
It focuses on kinematics, hyperelastic material behavior, the weak form of elastodynamics, spatial semi-discretization, and implicit time integration.
Pendulum-specific choices such as the geometry, pivot constraint, torque application, contact penalty, and stress visualization are described in the case study and implementation chapters.

\paragraph{Kinematics.}
Let $\Omega_0 \subset \mathbb{R}^d$, with $d \in \{2,3\}$, denote the reference configuration of a body.
A deformation map $\boldsymbol{\varphi} : \Omega_0 \to \mathbb{R}^d$ assigns each material point $\mathbf{X} \in \Omega_0$ its current position.
The displacement field is the difference between current and reference position,
\begin{equation}
    \mathbf{u}(\mathbf{X}) = \boldsymbol{\varphi}(\mathbf{X}) - \mathbf{X}.
\end{equation}
The deformation gradient
\begin{equation}
    \mathbf{F} = \nabla_0 \boldsymbol{\varphi}
    = \mathbf{I} + \nabla_0 \mathbf{u}
    \label{eq:fem_deformation_gradient}
\end{equation}
describes the local change of line elements.
A feasible deformation preserves orientation, which requires $J = \det \mathbf{F} > 0$.
The right Cauchy--Green tensor and the Green--Lagrange strain tensor are
\begin{equation}
    \mathbf{C} = \mathbf{F}^{\top}\mathbf{F},
    \qquad
    \mathbf{E} = \frac{1}{2}(\mathbf{C}-\mathbf{I}).
    \label{eq:fem_strain_measures}
\end{equation}
If $\mathbf{C} = \mathbf{I}$, the deformation is a rigid-body motion and should not create elastic strain.
This objectivity, also called frame indifference, is important for pendulum motion because large parts of the motion may be close to a rigid rotation while the elastic strain remains small~\cite{braess_finite_2007,kruzik_mathematical_2019}.

\paragraph{Constitutive Relation and Stress Measures.}
A material is called hyperelastic if the stored deformation energy can be described point-wise by a strain-energy density $W$.
In the reference configuration, the deformation energy can be written as
\begin{equation}
    E_{\mathrm{def}}(\mathbf{u})
    =
    \int_{\Omega_0} W(\mathbf{C}(\mathbf{u}))\,\mathrm{d}V .
    \label{eq:fem_deformation_energy}
\end{equation}
For objective materials, the energy depends on the deformation through $\mathbf{C}=\mathbf{F}^{\top}\mathbf{F}$.
For isotropic materials, the Rivlin--Ericksen theorem states that this dependence can be expressed through invariants of the strain tensor~\cite{braess_finite_2007,kruzik_mathematical_2019}.

The second Piola--Kirchhoff stress is obtained from the strain-energy density by
\begin{equation}
    \mathbf{S}
    =
    2\,\frac{\partial W}{\partial \mathbf{C}},
    \label{eq:fem_pk2}
\end{equation}
and the first Piola--Kirchhoff stress follows as
\begin{equation}
    \mathbf{P} = \mathbf{F}\mathbf{S}.
    \label{eq:fem_pk1}
\end{equation}

The first Piola--Kirchhoff stress appears naturally in the reference-configuration weak form.
The Cauchy stress in the current configuration is obtained by the push-forward
\begin{equation}
    \boldsymbol{\sigma}
    =
    \frac{1}{J}\mathbf{F}\mathbf{S}\mathbf{F}^{\top}.
    \label{eq:fem_cauchy_stress}
\end{equation}
This stress measure is used for physically interpretable stress quantities, for example von Mises stress.

\paragraph{Variational Formulation and Elastodynamics.}
The static elasticity problem can be stated as an energy minimization problem.
For a displacement space $V$ with prescribed Dirichlet boundary conditions on $\Gamma_D$, the total potential energy consists of the deformation energy and the potential of external volume and boundary forces,
\begin{equation}
    \mathcal{J}(\mathbf{u})
    =
    \int_{\Omega_0} W(\mathbf{C}(\mathbf{u}))\,\mathrm{d}V
    -
    \int_{\Omega_0} \mathbf{f}\cdot\mathbf{u}\,\mathrm{d}V
    -
    \int_{\Gamma_N} \mathbf{g}\cdot\mathbf{u}\,\mathrm{d}A .
    \label{eq:fem_total_energy}
\end{equation}
At an equilibrium point, the first variation of $\mathcal{J}$ vanishes for all admissible virtual displacements.
Equivalently, the internal virtual work equals the external virtual work.
In the linear variational setting this leads to a bilinear form and a linear form, and existence and uniqueness are classically characterized by the Lax--Milgram theorem~\cite{kochmann_introduction_2025}.

For the dynamic case, the balance of linear momentum in the reference configuration gives the strong form of nonlinear elastodynamics,
\begin{equation}
    \rho_0 \ddot{\mathbf{u}}
    =
    \nabla_0 \cdot \mathbf{P} + \mathbf{b}
    \qquad \text{in } \Omega_0 ,
    \label{eq:fem_strong_elastodynamics}
\end{equation}
where $\rho_0$ is the density in the reference configuration and $\mathbf{b}$ is a body force per unit reference volume.
The problem is completed by Dirichlet boundary conditions on $\Gamma_D$, Neumann boundary conditions on $\Gamma_N$, and initial conditions for displacement and velocity.
Multiplying the strong form by a test function $\mathbf{v}$ and integrating over $\Omega_0$ yields the weak form
\begin{equation}
    \int_{\Omega_0} \rho_0 \ddot{\mathbf{u}}\cdot\mathbf{v}\,\mathrm{d}V
    +
    \int_{\Omega_0} \mathbf{P}:\nabla_0 \mathbf{v}\,\mathrm{d}V
    =
    \int_{\Omega_0} \mathbf{b}\cdot\mathbf{v}\,\mathrm{d}V
    +
    \int_{\Gamma_N} \mathbf{t}_0\cdot\mathbf{v}\,\mathrm{d}A .
    \label{eq:fem_weak_elastodynamics}
\end{equation}
This weak form can also be interpreted through the principle of virtual work or, in dynamics, through the stationary action principle~\cite{kochmann_introduction_2025}.

\paragraph{Spatial Semi-Discretization.}
The finite element method replaces the infinite-dimensional displacement space by a finite-dimensional interpolation space.
With shape functions $N^a(\mathbf{X})$, the displacement field is approximated as
\begin{equation}
    \mathbf{u}^h(\mathbf{X},t)
    =
    \sum_{a=1}^{n_{\mathrm{n}}}
    N^a(\mathbf{X})\,\mathbf{U}^a(t),
    \label{eq:fem_interpolation}
\end{equation}
where $\mathbf{U}^a(t)$ are nodal unknowns and $n_{\mathrm{n}}$ is the number of nodes.
Inserting this approximation into the weak form and testing with all basis functions yields the semi-discrete equations of motion~\cite{kochmann_introduction_2025}
\begin{equation}
    \mathbf{M}\ddot{\mathbf{U}}(t)
    +
    \mathbf{F}_{\mathrm{int}}(\mathbf{U}(t))
    =
    \mathbf{F}_{\mathrm{ext}}(t).
    \label{eq:fem_semidiscrete}
\end{equation}
Here, $\mathbf{M}$ is the consistent mass matrix, $\mathbf{F}_{\mathrm{int}}$ collects the internal forces from the stress term, and $\mathbf{F}_{\mathrm{ext}}$ collects body forces and boundary tractions.
For nonlinear material laws or large-deformation kinematics, $\mathbf{F}_{\mathrm{int}}$ depends nonlinearly on the displacement vector.

\paragraph{Time Integration and Nonlinear Solution.}
After spatial semi-discretization, a time integration scheme is required to advance the nodal displacements, velocities, and accelerations.
The Newmark method is an implicit time-integration scheme for second-order structural dynamics problems.
In the average-acceleration form used here, the inertial contribution in the weak form is evaluated with the new acceleration~\cite{newmark_method_1959,kochmann_introduction_2025}
\begin{equation}
    \int_{\Omega_0}
    \rho_0\,
    \ddot{\mathbf{u}}^{n+1}(\mathbf{u}^{n+1})
    \cdot
    \mathbf{v}\,
    \mathrm{d}V .
    \label{eq:fem_newmark_inertia}
\end{equation}

For the finite-element simulation unit~$i$, local integration step~$r$ uses the step size $\Delta t_{i,r}$.
This notation distinguishes the internal finite-element step from the macro communication step of the co-simulation.
It is also suitable when the finite-element solver reduces its local step size near contact.
The new velocity and acceleration are expressed from the unknown displacement and the stored previous states by
\begin{align}
    \dot{\mathbf{u}}^{n+1}
    &=
    \frac{2}{\Delta t_{i,r}}
    \left(
        \mathbf{u}^{n+1}
        -
        \mathbf{u}^{n}
    \right)
    -
    \dot{\mathbf{u}}^{n},
    \label{eq:fem_newmark_velocity}
    \\
    \ddot{\mathbf{u}}^{n+1}
    &=
    \frac{2}{\Delta t_{i,r}}
    \left(
        \dot{\mathbf{u}}^{n+1}
        -
        \dot{\mathbf{u}}^{n}
    \right)
    -
    \ddot{\mathbf{u}}^{n}.
    \label{eq:fem_newmark_acceleration}
\end{align}

The time-discrete problem is therefore solved by first finding $\mathbf{u}^{n+1}$, typically with Newton's method.
The velocity $\dot{\mathbf{u}}^{n+1}$ and the acceleration $\ddot{\mathbf{u}}^{n+1}$ are then updated from the Newmark relations.
This time-discretization concept is sufficient to interpret the dynamic finite element model used in the controlled-pendulum case study.

\paragraph{Relation to the Pendulum Model.}
The pendulum of Section~\ref{sec:211_dynamical_systems} can also be represented as a deformable body.
In this formulation, the rigid rod and point mass are replaced by a continuum body.
Its motion is described by the displacement field $\mathbf{u}(\mathbf{X},t)$ rather than by a single generalized coordinate.
Loads such as gravity and actuation enter as volume or boundary forces, and the material law determines how deformation produces internal stress.

\paragraph{Interface Consequence.}
A finite element model contains many internal degrees of freedom, while a co-simulation interface exchanges only selected quantities.
Typical inputs are prescribed forces, tractions, or displacements on boundary regions.
Typical outputs are reaction forces, point displacements, field-derived quantities, or projected scalar variables.
If a finite element model is coupled to lower-dimensional models, selected field quantities must therefore be mapped to the shared interface variables.
For the pendulum case study, this mapping yields the same exposed angle and angular velocity as the rigid-body variants.
The concrete geometry, boundary regions, contact formulation, projection, and state-transfer choices are described in Section~\ref{sec:case_study_pendulum_fem}.

\subsection{Complementarity of Modeling Approaches}
\label{sec:modeling_complementarity}

The three modeling approaches introduced in this section represent the subsystems at different levels of abstraction.
Table~\ref{tab:modeling_complementarity} summarizes their role in the thesis.
The table is not a ranking of methods.
It shows why the controlled-pendulum case study requires a coupled simulation instead of one monolithic modeling approach.

\begin{table}[htbp]
    \centering
    \small
    \caption[Roles of modeling approaches]{Complementary roles of the modeling approaches used in this thesis.}
    \label{tab:modeling_complementarity}
    \begin{tabular}{@{}p{3.0cm}p{3.5cm}p{4.0cm}p{3.2cm}@{}}
        \toprule
        \textbf{Approach}
            & \textbf{Representation}
            & \textbf{Role in this thesis}
            & \textbf{Limitation} \\
        \midrule
        Equation-based
            & Lumped-parameter \acp{ODE} and \acp{DAE}
            & Closed-loop control, actuator dynamics, and rigid-body reference models
            & No spatial field resolution \\
        \addlinespace
        Musculoskeletal multibody
            & Rigid bodies, joints, and generalized coordinates
            & Domain-specific path for articulated-body dynamics
            & No local deformation field \\
        \addlinespace
        Finite element
            & Spatial displacement, strain, and stress fields
            & Deformable contact representation near the wall
            & High computational cost \\
        \bottomrule
    \end{tabular}
\end{table}

Equation-based models provide efficient system-level dynamics for controllers, drives, sensors, and rigid-body plant variants.
Musculoskeletal multibody models add a domain-specific representation for articulated motion and biomechanical tool integration.
Finite element models add spatially resolved deformation and contact fields at a substantially higher computational cost.

The approaches are therefore complementary.
A closed-loop biomechatronic simulation may require system-level control dynamics, articulated-body motion, and local structural effects in one scenario.
The co-simulation principles introduced in Section~\ref{sec:23_co_simulation} provide the coupling mechanism for this combination.
Each subsystem model keeps its own solver and exchanges data with the other simulation units at communication points.
Chapter~\ref{chap:architecture} defines the framework architecture that realizes this coupling.

\section*{Summary}
\addcontentsline{toc}{section}{Summary}

This chapter introduced the concepts used in the remainder of the thesis.
Continuous-time models define states, inputs, outputs, and direct-feedthrough relations.
Hybrid systems extend this view with events, resets, and dense-time ordering.
Co-simulation then combines several simulation units through communication points, with a master algorithm coordinating their advancement.

Two consequences are central for the framework developed in the following chapters.
First, the interconnection structure affects the admissible execution order.
Instantaneous dependencies may form algebraic loops, which must be detected and resolved before the simulation can advance consistently.
Second, simulation units keep their own internal solvers.
The master algorithm therefore coordinates data exchange and event handling without direct access to the internal equations of each unit.

The modeling approaches introduced in Section~\ref{sec:24_modeling_approaches} explain why this coupling is needed in the controlled-pendulum case study.
Equation-based models provide efficient lumped-parameter system dynamics.
Musculoskeletal multibody models provide a domain-specific representation of articulated motion.
Finite element models provide spatially resolved deformation and contact information.
The requirements in Chapter~\ref{chap:requirements} and the architecture in Chapter~\ref{chap:architecture} build on these concepts.
