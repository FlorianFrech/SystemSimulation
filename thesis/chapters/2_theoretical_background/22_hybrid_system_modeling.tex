\subsection{Hybrid System Representation}
\label{sec:221_hybrid_system_representation}

To analyze and simulate the hybrid systems introduced in Section~\ref{sec:intro_sota}, a formal representation is needed that captures both the continuous dynamics and the discrete transitions.

In this thesis, we use the reduced hybrid representation
\begin{equation}
    \Big(q(t), x(t), z(t), u(t), y(t)\Big),
\end{equation}
where $q(t)$ is the discrete state, $x(t)$ is the continuous state, $z(t)$ collects algebraic variables, $u(t)$ is the input, and $y(t)$ is the output.
The discrete state $q$ may represent an operating mode, a Boolean logic state, or an internal controller state.
This notation is a reduced representation inspired by formal hybrid modeling approaches such as Omola \cite{andersson_omola_1990,andersson_object-oriented_1994}.

Between events, the discrete state is constant, and the continuous part follows the active continuous-time model:
\begin{equation}
    0 = G_{q}\!\left(\dot{x}, x, z, u, t\right),
    \qquad
    y = h_{q}\!\left(x, z, u, t\right),
    \qquad t \neq t_\mathrm{e} .
\end{equation}
At an event time $t_\mathrm{e}$, the model performs an event update that may change its discrete state and may assign new values to selected continuous states:
\begin{equation}
    x^{+} = R_j\!\left(x^{-}, z^{-}, q^{-}, u^{-}, t_\mathrm{e}\right),
    \qquad
    q^{+} = \delta_j\!\left(x^{-}, z^{-}, q^{-}, u^{-}, t_\mathrm{e}\right).
\end{equation}
The function $R_j(\cdot)$ computes the post-event values of the continuous states, and the function $\delta_j(\cdot)$ updates the discrete state.
Here, $x^{-}$ and $q^{-}$ denote the values immediately before the event, and $x^{+}$ and $q^{+}$ denote the values immediately after the event.
This representation treats switching events and reset events uniformly.
A pure switching event is the special case $x^{+} = x^{-}$, so only the active mode or equations change.
A reset event is the case in which $R_j(\cdot)$ changes one or more continuous states instantaneously.
From the viewpoint of simulation, both cases are handled in the same way.
The event is localized, the update maps are evaluated, and the post-event model is re-initialized.
This unified interpretation is used later for the hybrid co-simulation algorithm.
The continuous state trajectory is therefore piecewise continuous, while the discrete state is piecewise constant \cite{van_der_schaft_introduction_2000,branicky_general_1995}.

The pendulum example introduced in Section~\ref{sec:211_dynamical_systems} can be extended to a hybrid system. The pendulum is in this case assumed to start swinging freely from an initial angle $\theta_0$ with initial velocity $\omega_0$ and hits a rigid wall at $\theta = \theta_\text{wall}$, modeled as an ideal elastic impact (see Figure~\ref{fig:pendulum_wall}).

The reset map $R_j$ evaluates to
\begin{equation}
    \theta^+ = \theta^-, \qquad \omega^+ = -\omega^-,
\end{equation}
expressing that the position is continuous at impact while the velocity
reverses instantaneously.
The discrete state update $\delta_j$ is trivial here since no mode switch occurs.
No discrete variables are involved, and the pendulum is governed by the same equations as before.

\subsection{Events, Zero-Crossings, and State Re-Initialization}
\label{sec:222_events_zerocrossing}

A central challenge in hybrid simulation is the consistent detection and handling of discrete events.
Two common trigger classes are distinguished.
Time events occur at known or scheduled instants and can therefore be handled by interrupting the continuous integration at prescribed times.
They do not require event-time localization by root finding.
State events, in contrast, depend on the continuous trajectory and are therefore not known a priori \cite{cellier_combined_1986,branicky_general_1995}.

In this thesis, state events are represented by event indicators, also called zero-crossing functions,
\begin{equation}
    \gamma_j\!\left(x, z, q, u, t\right).
\end{equation}
An event of type $j$ is triggered when the indicator crosses zero.

For the pendulum-wall example, the wall contact defines the event indicator
\begin{equation}
    \gamma_\text{contact}(\theta) = \theta - \theta_\text{wall}.
\end{equation}
The event occurs when $\gamma = 0$ in the defined event trigger direction
($\dot{\gamma} < 0$, i.e.\ the pendulum is moving toward the wall).
The resulting trajectories are shown in Figure~\ref{fig:pendulum_wall_trajectory}.

In numerical simulation, the state event time is usually not located exactly at the end of an integration step.
The simulator first detects that a zero-crossing occurred within a time interval.
It then localizes the event time inside this interval with a root-finding procedure.
This avoids integrating across a discontinuity without resolving its time of occurrence \cite{andersson_omola_1990,cellier_combined_1986}.

Once the event time $t_\mathrm{e}$ has been found, the event update maps introduced in Section~\ref{sec:221_hybrid_system_representation} are evaluated.
This step is the same for pure switching events and for events that reset continuous states.
The resulting post-event state must satisfy the active continuous and algebraic equations before simulation can continue.
This step is called state re-initialization or restart \cite{andersson_omola_1990,urquia_moraleda_modeling_2018}.

\subsection{Time Semantics in Hybrid Simulation}
\label{sec:223_hybrid_time_semantics}

When several discrete updates occur at the same physical instant, a real-valued time axis is insufficient to order them.
This occurs, for example, when one event triggers another event immediately, or when several event conditions become active at the same instant \cite{urquia_moraleda_modeling_2018}.

For this reason, hybrid simulation often uses \emph{superdense time}.
A time point is then represented by the pair
\begin{equation}
    (t,\nu),
\end{equation}
where $t \in \mathbb{R}_{\geq 0}$ denotes the physical time and $\nu \in \mathbb{N}_0$ denotes a logical micro-step index.
The physical time identifies when the event occurs.
The index $\nu$ orders the sequence of discrete updates at that same physical time.
An increase in $\nu$ does not represent additional physical time.
It only represents progress in the event iteration at fixed time $t$ \cite{broman_determinate_2013,cremona_hybrid_2019}.

Superdense time makes it possible to distinguish between the state before an event and the states after one or more discrete updates at the same physical time.
Continuous integration resumes only after all event updates at the current physical time have been processed.
This distinction is important for the present thesis, since hybrid co-simulation requires ordered event processing at a single physical time instant, as described in Section~\ref{sec:236_cosim_hybrid}.
