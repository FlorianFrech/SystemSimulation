\chapter{Feature Implementation and Verification}
\label{chap:implementation}

Chapter~\ref{chap:architecture} introduced the main architectural abstractions of \syssimx{}.
These include the component interface, the system model, the algorithm strategy, and the multi-model component.
This chapter describes how these abstractions are implemented and verified.
It covers the core framework features that realize the architecture in software.
The chapter starts with the port system and continues through the component interface, backend wrappers, system orchestration, execution algorithms, hybrid co-simulation, and multi-model switching.

Each section focuses on one framework feature.
It first states the requirement addressed by the feature.
It then explains the implementation approach and the relevant technical details.
Each section also summarizes the verification used to check the implemented behavior in isolation.
The full interaction of the implemented features is evaluated in the case study in Chapter~\ref{chap:case_study}.

The sections are ordered from foundational to advanced.
Section~\ref{sec:impl_port_system} describes the typed, unit-aware port system that underlies all data exchange.
Section~\ref{sec:impl_wrappers} presents the three backend-specific component wrappers that map external simulation tools to the common \texttt{CoSimComponent} interface.
Section~\ref{sec:impl_structural} describes the structural analysis of the
coupled system.
It builds the zero-delay dependency graph, identifies strongly connected
components, detects algebraic loops, and derives an execution order.
Section~\ref{sec:impl_algebraic_loops} describes how algebraic loops are
resolved once they have been identified by the structural analysis.
It focuses on the local iteration problem inside an instantaneous dependency
cycle.
Section~\ref{sec:impl_algorithms} describes the master algorithms that advance
the coupled system by macro time steps.
These algorithms use the execution order computed by the structural analysis.
They delegate algebraic loop resolution to the mechanism described in the
preceding section.
Section~\ref{sec:impl_hybrid} extends the stepping logic with event detection, localization, and rollback for hybrid co-simulation.
Finally, Section~\ref{sec:impl_multi_model} describes the multi-model switching mechanism with state adaptation and hysteresis.

The preceding sections verified the main framework features in isolation.
Together, these features provide the executable basis for assembling heterogeneous co-simulation scenarios with structural analysis, algebraic-loop resolution, hybrid event handling, and runtime model switching.
The next chapter evaluates their combined use in the controlled-pendulum case study.
There, the focus shifts from feature-level verification to system-level validation against the reference simulation and the intended application workflow.
