\section{Algebraic Loop Resolution}
\label{sec:impl_algebraic_loops}

The algebraic-loop implementation realizes \ref{req:SR-11-03} under \ref{req:UR-11}.
It uses the \ac{SCC}-local loop blocks detected by the structural analysis of Section~\ref{sec:impl_structural}.
The theoretical basis is introduced in Section~\ref{sec:235_cosim_algebraic_loops}.
When a master algorithm reaches a loop generation, \syssimx{} first computes consistent interface values.
The components in the loop block advance their states only after this correction.
The \pyfn{solve\_algebraic\_scc\_ijcsa()} helper performs the local \ac{IJCSA} correction for one \ac{SCC}.
The global \texttt{IJCSAAlgorithm} class solves the complete zero-delay interface and is described in Section~\ref{sec:impl_algorithms}.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Scope and Local Interface Data}
\label{sec:impl_algebraic_loops_scope}

The local solver operates on a single \ac{SCC} $A$.
It reuses the structural metadata stored on the \texttt{System} instance.
From the zero-delay connections incident to $A$, it derives the local interface problem.

The unknown vector
\begin{equation}
  U_{A} = \bigl(u_1,\ldots,u_n\bigr)^\top
\end{equation}
collects every destination input port of a zero-delay connection inside $A$.
The \pyfn{driver\_for\_input} map assigns each entry of $U_A$ to its driving source output.
Internal connections are zero-delay edges whose source and destination components both belong to $A$.
External incoming connections enter $A$ from earlier generations.
Their driver outputs are read once at the current communication point and remain fixed during the local solve.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Residual Evaluation}
\label{sec:impl_algebraic_loops_residual}

For a trial vector $U_{A}$, the solver assembles temporary inputs for every component in $A$.
These inputs contain the trial values and the fixed external values.
The solver then calls \pyfn{evaluate\_outputs(inputs)} on each component.

Routing the returned outputs through \pyfn{driver\_for\_input} yields the induced interface vector $\widehat{U}_{A}(U_{A})$.
The residual is
\begin{equation}
  \mathcal{R}_{A}(U_{A}) = U_{A} - \widehat{U}_{A}(U_{A}),
\end{equation}
which matches the fixed-point form of Section~\ref{sec:235_cosim_algebraic_loops} restricted to $A$.
A consistent loop state is reached when $\|\mathcal{R}_{A}\|_2$ falls below the solver tolerance.
Because \pyfn{evaluate\_outputs()} does not advance component state, the residual can be sampled at several trial vectors within one macro step.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Newton Iteration and Commit}
\label{sec:impl_algebraic_loops_newton}

The iteration starts from the values currently stored in the destination input ports of $A$.
These values are the most recent consistent inputs from the previous macro step.
Each iteration approximates the interface Jacobian column-wise by forward finite differences,
\begin{equation}
  J^{(m)}_{:,j} \approx
  \frac{
    \mathcal{R}_{A}\!\bigl(U_{A}^{(m)} + \varepsilon e_j\bigr)
    - \mathcal{R}_{A}\!\bigl(U_{A}^{(m)}\bigr)
  }{\varepsilon},
  \qquad \varepsilon = 10^{-6},
\end{equation}
and applies the standard Newton update $U_{A}^{(m+1)} = U_{A}^{(m)} - \bigl(J^{(m)}\bigr)^{-1}\mathcal{R}_{A}(U_{A}^{(m)})$.

The loop terminates when $\|\mathcal{R}_{A}\|_2<\texttt{tol}$.
If the Jacobian is singular, the solver aborts the current macro step with a runtime error.
It also aborts when the residual does not converge within \texttt{max\_iter} iterations.
This prevents inconsistent interface inputs from being committed.
The Jacobian becomes singular when the loop-gain eigenvalue approaches one, for example for an identity feedback $y=u$ or a unit-gain cycle.
Finite-difference noise at discontinuities can produce the same condition numerically.

After convergence, the solver writes the solved entries of $U_A$ back to the corresponding destination input ports.
It uses \pyfn{inputs[dst].set(value, t)} for this commit.
The loop inputs are then mutually consistent at the current communication point, while the component states are still unchanged.
The active master algorithm subsequently performs the macro step with these committed values.

\subsection{Verification Scenario}
\label{sec:impl_algebraic_loops_verification}

The verification scenario of Figure~\ref{fig:algebraic_loop_verification} consists of a constant source, two subtractors, and one integrator.
The labels on the ports define the notation used below.

\begin{figure}[!htbp]
  \centering
  \includegraphics[width=0.9\linewidth]{figures/5_implementation/algebraic_loop/algebraic_loop_verification.pdf}
  \caption[Algebraic-loop verification scenario.]{Verification scenario for algebraic-loop resolution.
  The dashed red rectangle marks the \ac{SCC} node set $A=\{\texttt{Inner}\}$.
  Wire routing is purely visual and does not indicate \ac{SCC} membership.}
  \label{fig:algebraic_loop_verification}
\end{figure}

The \texttt{Source} emits $s=1$.
The two subtractors \texttt{Inner} and \texttt{Outer} are direct-feedthrough components with output equation $d_o=p_o-n_o$ and $d=p-n$ respectively.
The \texttt{Integrator} advances $\dot{x}=u$ with $x(0)=0$ and has no feedthrough.
Five connections close the topology.
The source drives the positive input of \texttt{Outer}.
The output of \texttt{Outer} drives the positive input of \texttt{Inner}.
The output of \texttt{Inner} drives the integrator input and is also fed back to its own negative input.
The integrator output drives the negative input of \texttt{Outer}.
This last connection is delayed because the integrator has no direct feedthrough from $u$ to $x$.

The self-connection $d\to n$ is the only zero-delay cycle, so the structural analysis stores a single \ac{SCC} $A=\{\texttt{Inner}\}$.
For the local solve, $n$ is the only interface unknown and the edge $d_o\to p$ appears as the one external incoming connection held fixed at the current communication point.
At $t=0$ the integrator output is zero, so the external value reduces to $p=s-x=1$.
The local problem collapses to the scalar fixed-point equation $n=p-n$ with analytical solution $n=d=\tfrac{1}{2}p=0.5$.
