\subsection{Finite-Element Model Wrapper}
\label{sec:impl_fem}

Finite-element models are integrated through the same \texttt{CoSimComponent} contract as the other component types.
The \texttt{FEMComponent} class provides the framework entry point for finite-element components and realizes \ref{req:SR-07-01} under \ref{req:UR-07}.
It derives from \texttt{CoSimComponent} and collects attributes that are commonly needed by finite-element implementations.
These include geometry, mesh data, finite-element spaces, grid functions, forms, solver handles, and visualization state.

The reusable part of the finite-element wrapper is intentionally small.
Finite-element components differ in mesh representation, weak form, material law, boundary conditions, time integration, and solver state.
The concrete \ac{FEM} component therefore defines the port interface, discretization, numerical problem, time advancement, output projection, state transfer, and rollback behavior.

The controlled-pendulum case study uses the \texttt{FEMPendulum} class as the concrete finite-element component.
It implements the NGSolve model used for the contact-relevant pendulum phases.
The component constructs the finite-element spaces and grid functions, assembles the nonlinear problem, advances the model in time, and maps the \ac{FEM} state to the exposed pendulum outputs.
State transfer and rollback are implemented there because they depend on the selected time integration scheme and on the grid-function vectors that must be restored.

This compact wrapper keeps the framework interface consistent without imposing a generic finite-element backend abstraction.
The numerical formulation and verification of the concrete \ac{FEM} pendulum are part of the controlled-pendulum case study in Chapter~\ref{chap:case_study}.
