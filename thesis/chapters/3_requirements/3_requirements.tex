This chapter defines the requirements for the \syssimx{} framework and justifies the external tools used in this thesis.
\Acp{UR} state the capabilities expected from the system simulation workflow.
\Acp{SR} state the framework features that realize these capabilities.

The two requirement levels are evaluated at different points in the thesis.
Chapter~\ref{chap:implementation} verifies the \acp{SR} through feature-level verification scenarios.
Chapter~\ref{chap:case_study} validates the mandatory \acp{UR} through the controlled-pendulum case study.
The corresponding sections reference the \ac{UR} and \ac{SR} identifiers that they address.

The requirements follow from the target application scenario of mechatronic devices coupled with the human musculoskeletal system.
They also reflect the orchestration gap identified in Chapter~\ref{chap:intro} and the modeling approaches discussed in Section~\ref{sec:24_modeling_approaches}.

\section{Requirements}

The requirements are formulated in a tool-agnostic way.
They describe user needs and framework capabilities, not implementation mechanisms.
Mandatory requirements use \emph{shall}.
Recommended requirements use \emph{should}.
The general system modeling, heterogeneous integration, and simulation categories contain mandatory requirements.
The interaction category contains recommended requirements that support inspection and post-processing workflows but are not required for the core simulation contract.
