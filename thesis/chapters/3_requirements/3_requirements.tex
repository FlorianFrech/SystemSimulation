\chapter{Requirements and Tool Selection}
\label{chap:requirements}

This chapter defines the requirements on the \emph{SysSimX} framework and the selection of the external tools used in this thesis.
The requirements were elicited iteratively from stakeholder discussions, the target application scenario, and an analysis of existing modeling and simulation tools.
First, user requirements were formulated to describe the expected capabilities of the system simulation workflow.
Second, technical system requirements were derived from these user requirements to guide the architecture and implementation.

\section{Requirements}

The requirements are formulated in a tool-agnostic way and focus on user 
needs rather than implementation details.
All functional requirements are mandatory.
