\subsection{Heterogeneous Integration}
\label{sec:req_heterogeneous_integration}

The heterogeneous integration requirements describe the need to integrate subsystem models from different modeling and simulation backends into one coupled workflow.
As established in Section~\ref{sec:intro_sota}, no single existing tool covers all required modeling approaches.
This motivates a common integration interface that is independent of any particular backend.

This category also includes runtime model switching, which relies on a shared simulation-unit interface to transfer state between models during simulation.
