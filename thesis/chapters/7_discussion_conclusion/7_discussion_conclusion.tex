\chapter{Discussion and Conclusion}
\label{chap:discussion_conclusion}

This chapter synthesizes the implementation and case-study results with respect to the research questions stated in Chapter~\ref{chap:intro}.
The thesis set out to develop and evaluate \syssimx{} as a framework for heterogeneous hybrid co-simulation.
The preceding chapters showed how the framework represents heterogeneous subsystem models through a shared component abstraction, derives structural execution metadata, handles algebraic loops and hybrid events, and supports runtime switching between alternative models of the same subsystem.

The discussion first relates these results to the five research questions.
It explains which parts of the framework answer the questions on heterogeneous integration, dependency-aware orchestration, hybrid event handling, runtime model switching, and representative case-study behavior.
It then interprets the controlled-pendulum results and the performance benchmark.
The interpretation distinguishes numerical verification against monolithic OpenModelica references, workflow validation of the combined framework features, and runtime benchmarking.

The chapter also states the limits of the work.
The case study does not constitute experimental physical validation.
The reference models are numerical comparison models, and the performance results are specific to the selected pendulum configuration, model parameters, solver settings, and hardware.
Based on these boundaries, the chapter concludes the thesis and identifies future work for stronger backend support, adaptive algorithms, improved state projection, and broader validation scenarios.
