\chapter{Framework Architecture}
\label{chap:architecture}

This chapter describes the architecture of \syssimx{}.
It connects the requirements of Chapter~\ref{chap:requirements} to the implementation in Chapter~\ref{chap:implementation}.
The focus is on responsibilities, interfaces, and ownership relations between the main framework abstractions.

Section~\ref{sec:architecture_overview} introduces the layered framework structure and the design principles behind it.
Section~\ref{sec:architecture_core_abstractions} presents the core framework abstractions.
These are the component interface, the port and connection model, the \texttt{System} abstraction, the algorithm interface, and the multi-model component.
Chapter~\ref{chap:implementation} then covers class-level mechanisms, stored metadata, and feature-level verification.
