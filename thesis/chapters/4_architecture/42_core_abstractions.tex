\section{Core Abstractions}
\label{sec:architecture_core_abstractions}

This section describes the abstractions that define the framework contract of \syssimx{}.
The component interface defines how simulation backends enter the framework.
The \texttt{System} abstraction defines how components are connected.
The algorithm interface defines how a connected system is advanced in time.
The multi-model component extends the same contract to interchangeable model representations.
