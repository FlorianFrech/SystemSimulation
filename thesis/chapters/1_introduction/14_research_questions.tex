\section{Research Questions}
\label{sec:intro_research_questions}

This thesis investigates how heterogeneous subsystem models from different simulation environments can be integrated into a coherent system-level simulation workflow.
The central research question is:

\textit{How can a framework support heterogeneous hybrid co-simulation of subsystem models from different tools while providing consistent orchestration, event handling, and runtime switching between alternative models of the same subsystem?}

To answer this main question, the following sub-questions are addressed:

\begin{enumerate}
    \item[\textbf{RQ1}] How can heterogeneous subsystem models from equation-based, musculoskeletal, and finite element analysis tools be represented through a unified component interface for co-simulation?

    \item[\textbf{RQ2}] How can dependencies between heterogeneous simulation units be analyzed to derive a consistent execution order and identify direct feedthrough and algebraic loops?

    \item[\textbf{RQ3}] How can hybrid phenomena, such as contact, switching, and discrete state changes, be detected, localized, and handled within one co-simulation workflow?

    \item[\textbf{RQ4}] How can runtime switching between alternative subsystem models be performed while preserving the shared state variables needed by the coupled simulation?
    
    \item[\textbf{RQ5}] To what extent can the framework reproduce results from monolithic model-based references on the controlled-pendulum case study, and what is the runtime cost of selected configurations?

\end{enumerate}
