\section{Objectives}
\label{sec:intro_objectives}

Based on these research questions, the overall objective of this thesis is to develop and evaluate \syssimx{} as a practical framework for heterogeneous hybrid system simulation.
The thesis pursues the following objectives:

\begin{enumerate}
    \item[\textbf{O1}] Design a unified component abstraction for heterogeneous subsystem models.

    \item[\textbf{O2}] Develop graph-based orchestration for coupled subsystem models, including dependency analysis and execution-order resolution.

    \item[\textbf{O3}] Implement direct-feedthrough analysis and algebraic-loop handling within the orchestration workflow.

    \item[\textbf{O4}] Integrate hybrid event handling, including event detection, event localization, event dispatch, and continuation after events.

    \item[\textbf{O5}] Develop a multi-model component concept for runtime switching between alternative subsystem models with state transfer at the shared interface.

    \item[\textbf{O6}] Apply the framework to a controlled-pendulum case study combining \acp{FMU}, OpenSim, and \ac{FEM} models.

    \item[\textbf{O7}] Evaluate the framework through feature-level verification, numerical comparison with model-based references, and representative runtime benchmarks.
\end{enumerate}
