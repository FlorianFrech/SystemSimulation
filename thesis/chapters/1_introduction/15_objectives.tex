\section{Objectives}

Based on these research questions, the overall objective of this thesis is to develop and evaluate the \syssimx{} framework as a practical approach for heterogeneous hybrid system simulation.
In particular, the thesis pursues the following objectives:

\begin{enumerate}
    \item[\textbf{O1}] Design a unified component-based abstraction for heterogeneous subsystem models.

    \item[\textbf{O2}] Develop a graph-based orchestration concept for coupled system models, including dependency analysis and execution-order resolution.

    \item[\textbf{O3}] Implement support for direct feedthrough analysis and algebraic-loop handling within the orchestration workflow.

    \item[\textbf{O4}] Integrate hybrid event handling, including event detection, event localization, and event execution, into the framework.

    \item[\textbf{O5}] Develop a multi-model component concept that enables runtime switching between alternative subsystem models with consistent state synchronization.

    \item[\textbf{O6}] Apply the framework to a controlled-pendulum case study combining FMU, OpenSim, and FEM models.

    \item[\textbf{O7}] Evaluate the framework with respect to functional correctness, consistency of coupled behavior, and practical applicability in representative simulation scenarios.
\end{enumerate}
