\section{Problem Statement and Research Gap}
\label{sec:intro_gap_contribution}

Equation-based simulation, musculoskeletal simulation, finite element analysis, and \ac{FMI}-based co-simulation are established within their respective domains.
Many mechatronic and biomechanical systems require these modeling approaches to be combined within one system-level simulation workflow.
This integration remains difficult in practice.
Existing approaches are strong either in standardized \ac{FMU}-based coupling or in domain-specific analysis, but they provide only limited support for integrating \ac{FMU} models, musculoskeletal models, and finite element models within one common simulation environment.

The gap becomes more restrictive when heterogeneous tool coupling must be combined with dependency-aware execution, algebraic-loop handling, hybrid event handling, and runtime switching between alternative subsystem models.
Such a combined workflow is still insufficiently addressed for systems whose relevant physics and suitable model representation change across operating phases.
This is the case, for example, when a simulation transitions between free motion, human interaction, and contact-dominated behavior.

Table~\ref{tab:framework_comparison} summarizes this gap for representative \ac{FMI}-based co-simulation frameworks.
These frameworks support \ac{FMU} coupling and algebraic-loop handling, but none combines native musculoskeletal \ac{MBD} and \ac{FEM} backends with hybrid event handling and runtime model switching.

This thesis addresses this gap with \syssimx{}.
The main contribution is the design, implementation, and evaluation of its orchestration layer for heterogeneous hybrid co-simulation.
Within this contribution, the thesis develops:
\begin{itemize}
    \item a unified component abstraction for heterogeneous subsystem models,
    \item graph-based structural analysis for dependency detection, execution-order resolution, and algebraic-loop identification,
    \item hybrid event handling for detection, localization, dispatch, and cascaded event processing, and
    \item a multi-model component concept for runtime switching between alternative subsystem models with state synchronization.
\end{itemize}
The controlled pendulum serves as the evaluation system for this framework.
It is not a new modeling contribution.
It combines \acp{FMU}, OpenSim, and \ac{FEM} models in one closed-loop scenario and exercises the framework features together.
